# fnote

**Markdownで書く、階層で整理する、タグで見つける**

fnoteは、VS Codeでメモや作業記録を管理する拡張機能です。プロジェクトごとにノートをまとめ、エディタを離れずに複数のノートからタスクや記録を探せます。

- **階層で整理**：親子ノートや見出しでまとめ、ドラッグ＆ドロップで移動。
- **タグで検索**：`@TODO`、日付タグ、キーワードで必要な情報を検索。
- **作業時間を集計**：日付と時間を書くだけで、日・月・年ごとの合計を確認。
- **手元のファイルで管理**：Markdownと添付ファイルをローカルに保存。既定ではワークスペースを切り替えても同じノートを利用。

## 使い方

### ノートを作る

1. アクティビティバーの **Fnote** を開きます。
2. **Fnote - List** の **＋** をクリックし、ノート名を入力します。
3. Markdownエディタで本文を書き、Macでは `Cmd + S`、Windowsでは `Ctrl + S` で保存します。

```markdown
# 今日の作業

## タスク
@TODO READMEを更新する
@仕事/会議 次回の議題を整理する

## 作業記録
@2026/09/21 @30m ドキュメントを整理した
```

![ノートを作る](media/screenshots/create-note.png)

### ノートを探す

**Fnote - Tags** の `TODO` をクリックすると、該当ノートと本文行を表示します。結果をクリックすると、元のノートのその位置へ移動できます。タグ横の数字は、子タグを含み、アーカイブ済みを除いた一致ノート数です。

![タグでノートを探す](media/screenshots/tag-search.png)

タグは本文に `@タグ名` と書くだけで使えます。`@仕事/会議` のように `/` で階層化でき、親タグを選ぶと子タグも検索対象になります。大文字・小文字は区別します。コード内、メールアドレス内、`\@` でエスケープした文字はタグになりません。同じ階層のタグはドラッグで並べ替えられます。

キーワードで探すときは **Fnote - List** の虫眼鏡をクリックします。ノート名と本文を大文字・小文字を区別せずに検索し、アーカイブ済みノートも対象になります。

### 整理・移動する

ノートの右クリックメニューから **Add Child Note**（子ノートの追加）、**Rename**（名前の変更）、**Move**（移動）、**Delete**（削除）を選べます。ドラッグ先の行の中央で子ノートに、上端・下端で前後に並べ替え、一覧下部の空白で最上位に移動します。親を移動すると子ノートも一緒に移動します。

ノート内を分けるには `##`〜`######` の見出しを使います。一覧の見出しをクリックすると本文の該当位置を開けます。最初の `#` 見出しがノートの表示名になり、**Rename** では見出しとフォルダー名の両方が変わります。

ノート一覧にフォーカスがあるときは、次のキーで操作できます。

| 操作                                 | Mac               | Windows    |
|--------------------------------------|-------------------|------------|
| ノート作成（ノート選択時は子ノート） | `Cmd + N`         | `Ctrl + N` |
| ノート・添付ファイルの名前変更       | `F2`              | `F2`       |
| ノート・添付ファイルの削除           | `Cmd + Backspace` | `Delete`   |
| 選択の移動                           | `↑` / `↓`         | `↑` / `↓`  |
| 選択したノート・添付ファイルを開く   | `Enter`           | `Enter`    |

上下キーでは選択だけを移動し、`Enter` で開いてもフォーカスは一覧に残ります。表示中のノートの背景色と、キー操作で選択している行の枠線を分けて表示します。

タグ一覧でも、タグ検索結果を開いた後にフォーカスが一覧に残るため、マウスを使わずに `↑` / `↓` でタグ間を移動できます。

一覧のタイトルバーから、全体の展開・折りたたみや、開いているfnoteのノート・検索結果をまとめて閉じる操作もできます。

## 便利な機能

### 作業時間の集計

**同じ行**に日付を1つと、所要時間または開始・終了時刻を書きます。

```markdown
@2026/09/21 @30m ドキュメントを更新
@2026/09/21 @10:00-11:00 操作を確認
@2026/09/22 @1h 次の機能を検討
```

タグ一覧で `2026` → `09` → `21` を選ぶと、この日の合計 **1h30m** を表示します。月や年を選べば、その期間の合計を確認できます。

![日別の作業時間の合計](media/screenshots/daily-total.png)

日付は `@YYYY/MM/DD`、所要時間は整数で `@30m`・`@1h`、時刻範囲は `@10:00-11:00` と書きます。時間タグ自体はタグ一覧に表示しません。

入力途中の `@10:00` や `@10:00-` は **Incomplete time tags** にまとめるので、記入漏れを見つけて続きを入力できます。未完了の時刻は合計に含めません。

### 添付ファイルとリンク

ノートの右クリックメニューの **Add Attachment** を使うか、外部のファイルを **Shiftを押しながら** 一覧のノート行やMarkdownエディタへドロップします。一覧にはフォルダーも添付できます。エディタへ添付する場合は `editor.dropIntoEditor.enabled` を有効にし、選択肢が出たら **Copy attachments into fnote** を選びます。

添付ファイルはノートの下に表示され、開く・名前変更・削除のほか、一覧内のドラッグで別のノートへ移動できます。一覧内のノートや添付ファイルの移動にShiftは不要です。

別のノートへのリンクは `[[../旅行]]` や `[旅行予定](../旅行)` と書きます。`[](#title)` のように書くと現在のノートの見出しへ、別ノートへのリンクにフラグメントを付けると別ノートの見出しへ移動できます。Ctrl+クリックでリンクを開けます。フォルダーを指定すると中の `index.md` を開きます。ノートの移動・名前変更時には、対応する相対MarkdownリンクとWikiリンクも更新します。

リンクはアイコンと表示名またはリンク先で表示します。カーソルを重ねると元の記法を編集でき、保存するMarkdownは変わりません。

### 完了したノートのアーカイブ

ノートの右クリックメニューの **Archive** で設定・解除します。**✓ Archive** はアーカイブ済みを表し、既定では灰色のarchiveアイコンで表示します。

子ノートがある場合は、そのノートと子孫すべてに変更を適用するか確認します。子の状態を変えても親の状態は変わりません。

アーカイブ済みノートはノート一覧に残り、タグ検索結果・タグ横の件数・日付タグからの時間集計から除外されます。状態は各ノートフォルダーの `.status` に保存し、コピーや移動後も引き継ぎます。

## 設定変更

VS Codeの設定画面で **`@ext:maoren.fnote`** を検索すると、fnoteの設定を表示できます。以下のJSON例は、コマンドパレットの **Preferences: Open User Settings (JSON)** から、既存の `{ ... }` 内へ追加してください。

### アイコンと色

タグごとの設定には `fnote.tagStyles` を使います。アイコンには文字・絵文字・`$(book)` などのVS Codeアイコン名を指定できます。

利用できるVS Codeアイコンは、[VS Code Codicons](https://microsoft.github.io/vscode-codicons/dist/codicon.html) の一覧で確認できます。

```json
{
  "fnote.tagStyles": [
    { "tag": "TODO", "mark": "$(circle-filled-compact)", "markColor": "#FF5555", "color": "#FF5555" },
    { "tag": "完了", "mark": "✅", "color": "#66BB6A" },
    { "tag": "参考", "mark": "$(book)", "excludeFromNoteMark": true },
    { "tag": "Incomplete time tags", "mark": "$(clock)", "color": "#fbbf24", "excludeFromNoteMark": true },
    { "tag": "date", "mark": "$(calendar)", "excludeFromNoteMark": true }
  ],
  "fnote.headingMark": "#",
  "fnote.headingMarkColor": "#808080",
  "fnote.archiveMark": "$(archive)",
  "fnote.archiveColor": "#808080"
}
```

`markColor` はアイコン色、`color` と `backgroundColor` はタグの文字色と背景色です。`date` は日付タグ共通の設定です。`excludeFromNoteMark` を有効にすると、タグ一覧には残しつつノートのアイコン候補から除外できます。

ノートのアイコンは配列の上の設定を優先し、日付・時間タグは候補にしません。子タグは独自の指定がなければ親のアイコンを引き継ぎます。`fnote.tagStyles` を指定すると既定の配列を置き換えるため、残したい項目も含めてください。見た目の変更は再起動せずに反映されます。

| 設定                                             | 用途                                                  |
|--------------------------------------------------|-------------------------------------------------------|
| `fnote.untaggedNoteMark`                         | アイコン候補のタグがないノートの印（`$(note)`）       |
| `fnote.defaultTagMark`                           | タグの既定アイコン（`$(circle-filled-compact)`）      |
| `fnote.tagColor` / `fnote.tagBackgroundColor`    | タグの既定文字色・背景色                              |
| `fnote.headingMark` / `fnote.headingMarkColor`   | ノート一覧のMarkdown見出しに付ける印と色（`#`、`#808080`） |
| `fnote.linkMark`                                 | リンクのアイコン（`$(link-external)`）                |
| `fnote.attachmentMark` / `fnote.attachmentColor` | 添付のアイコン（`$(attach)`）と色                     |
| `fnote.archiveMark` / `fnote.archiveColor`       | アーカイブのアイコン（`$(archive)`）と色（`#808080`） |

### タグのグループ化

本文のタグ名を変更せずに、既存のタグをまとめられます。

```json
{
  "fnote.tagHierarchy": {
    "状態": ["TODO", "完了"]
  }
}
```

**状態** を選ぶと、いずれかの子タグに一致するノートを表示します。

### 保存先とバックアップ

ノートは `<ノートのフォルダー>/index.md` に保存し、同じフォルダー内に子ノートや添付ファイルを配置します。既定の保存先は **`~/.fnote`** で、ワークスペース間で共通です。

現在のワークスペースに保存する場合は、次のように設定します。

```json
{
  "fnote.storagePath": "${workspace}/.fnote"
}
```

`~/Documents/fnote` や `C:/Users/your-name/Documents/fnote` などの絶対パスも指定できます。`${workspace}` と `${workspaceFolder}` は最初のワークスペースフォルダーを指します。変更後は **Developer: Reload Window** を実行してください。

既存のノートは自動で移動しないため、保存してから新しい場所へフォルダーをコピーし、設定を切り替えます。バックアップは `.status` を含む保存先フォルダー全体をコピーすると、ノート・添付・アーカイブ状態・ノートの並び順を残せます。ルートの `.status` にはトップレベルのノート順を、各ノートの `.status` にはその直下にある子ノートの順番を保存します。
