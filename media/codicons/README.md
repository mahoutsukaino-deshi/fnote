# Codicons

Source: https://github.com/microsoft/vscode-codicons
Distribution: https://microsoft.github.io/vscode-codicons/dist/
Downloaded: 2026-09-17

Copyright Microsoft Corporation. Icons are licensed under CC BY 4.0 (LICENSE);
code is licensed under MIT (LICENSE-CODE). CSS and font are distributed unmodified.

`paths.json` contains outlines derived from the bundled font for editor
link decorations. Glyph outlines are unchanged; SVG format and foreground
colors are applied at runtime. Regenerate with
`python3 scripts/generate-codicon-paths.py` (requires fontTools).
